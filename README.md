# Soleman Jewellers - Gold & Silver Management System

এটি একটি ওয়েব অ্যাপ্লিকেশন যা স্বর্ণ ও রূপার কেনাবেচা, বিনিময়, পুরাতন থেকে নতুন, এবং স্বর্ণ ঋণ ক্যালকুলেশন করে। ডেটা সার্ভারে JSON ফাইলে সংরক্ষিত হয়।

## ফাইল স্ট্রাকচার
- `index.html` – মূল অ্যাপ্লিকেশন
- `server.php` – সমস্ত ডেটা (বিল, লোন, সেটিংস) সংরক্ষণ ও পুনরুদ্ধার
- `save_price.php` – গোল্ড ও সিলভারের দাম সংরক্ষণ
- `price.json` – ডিফল্ট দাম
- `data/` – এখানে JSON ফাইলগুলো তৈরি হবে (`.gitignore`-এ রাখুন)

## ইনস্টলেশন
1. সব ফাইল আপনার হোস্টিং-এ আপলোড করুন।
2. `data/` ফোল্ডার তৈরি করুন এবং লেখার অনুমতি দিন (chmod 755 বা 777)।
3. ব্রাউজারে `index.html` খুলুন।

## Git ব্যবহার
- রেপো ক্লোন করুন।
- পরিবর্তন কমিট করে পুশ করুন।
- `data/` ফোল্ডার কখনো Git-এ যাবে না (`.gitignore`-এর কারণে)।

## লাইসেন্স
প্রাইভেট প্রকল্প – শুধুমাত্র Soleman Jewellers-এর জন্য।
